# Face checkpoint terms

HAT-S Face and HAT-L Face are research-derived checkpoints with unresolved
training-data and weight rights. Apache-2.0 applies to the HAT implementation;
it does not independently establish permission to redistribute or commercially
use a fine-tuned checkpoint.

LocalSR labels both variants Labs, disables automatic acquisition, and verifies
an exact user-supplied copy by size and SHA-256. Use a copy only where you are
independently permitted to do so. The existing HAT-S release does not settle
these rights. HAT-L weights are not published by this integration.

See the [HAT-S card](models/hat-s-face.md) and [HAT-L card](models/hat-l-face.md)
for exact checkpoint identities, measured trade-offs, and availability.
